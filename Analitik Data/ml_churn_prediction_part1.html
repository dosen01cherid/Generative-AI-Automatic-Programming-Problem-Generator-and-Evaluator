Customer Churn Prediction for Internet Service Provider

Part 1: Business Context, Dataset Generation & Exploratory Data Analysis

📊 1. Business Context & Problem Definition

🌐 TeleConnect ISP - Company Profile

  • Industry: Internet Service Provider (ISP)
  • Services: Fiber optic internet, DSL, Cable internet
  • Customer Base: 50,000+ residential and business customers
  • Market: Highly competitive telecom market
  • Current Challenge: High customer churn rate (25% annually)

🎯 The Business Problem

TeleConnect ISP is facing a critical business challenge: customer churn. Approximately 25% of their customers discontinue their service annually, which translates to significant revenue loss and increased customer acquisition costs.

💰 Financial Impact

Cost to acquire new customer: $500 - $800 per customer (marketing, sales, installation)

Cost to retain existing customer: $50 - $100 per customer (promotional offers, customer service)

Annual revenue per customer: $1,200 (average)

Losing a customer means not just losing their annual revenue ($1,200), but also the high acquisition cost ($500-$800) becomes a sunk cost. Industry research shows that retaining customers is 5-25 times cheaper than acquiring new ones.

🤔 Why Machine Learning?

Traditional approaches to churn management are reactive - the company only knows a customer has churned after they've left. Machine Learning enables a proactive approach:

  1. Predict Before They Leave: Identify customers likely to churn before they actually cancel
  2. Targeted Retention: Focus retention efforts on high-risk customers (better ROI)
  3. Personalized Interventions: Understand churn drivers for different customer segments
  4. Optimize Resources: Allocate retention budget efficiently
  5. Measure Impact: Track effectiveness of retention campaigns

🎯 Business Objectives

The ML project aims to:

  • Build a model to predict which customers are likely to churn in the next 3 months
  • Achieve at least 80% accuracy in identifying churners
  • Reduce churn rate from 25% to 18% (saving ~$4.2M annually)
  • Enable customer service team to proactively reach out to at-risk customers

Expected ROI Calculation

\[ \text{Annual Savings} = (\text{Customers Saved}) \times (\text{Annual Revenue} - \text{Retention Cost}) \]

\[ = (50000 \times 0.07) \times (1200 - 100) = 3500 \times 1100 = \$3,850,000 \]

🔨 3. Generate Synthetic Dataset

Since we're learning, we'll create a realistic synthetic dataset that mimics the characteristics of actual ISP customer data. This dataset will include realistic patterns that you'd find in real-world churn scenarios.

1Dataset Generation Code

Run this code to generate the dataset:

import pandas as pd
import numpy as np
from datetime import datetime
import matplotlib.pyplot as plt
import seaborn as sns

# Set random seed for reproducibility
np.random.seed(42)

# Number of customers
n_customers = 5000

# Generate customer IDs
customer_ids = [f'CUST{str(i).zfill(6)}' for i in range(1, n_customers + 1)]

# Generate tenure (months) - weighted towards newer and longer customers
tenure = np.concatenate([
    np.random.randint(1, 12, size=int(n_customers * 0.3)),    # 30% new customers
    np.random.randint(12, 36, size=int(n_customers * 0.4)),   # 40% mid-tenure
    np.random.randint(36, 72, size=int(n_customers * 0.3))    # 30% loyal customers
])
np.random.shuffle(tenure)

# Contract types
contract_types = np.random.choice(
    ['Month-to-month', 'One year', 'Two year'],
    size=n_customers,
    p=[0.55, 0.25, 0.20]  # Month-to-month is most common
)

# Internet service types
internet_services = np.random.choice(
    ['DSL', 'Fiber optic', 'Cable'],
    size=n_customers,
    p=[0.30, 0.45, 0.25]  # Fiber optic is most popular
)

# Generate monthly charges based on internet service type
monthly_charges = []
for service in internet_services:
    if service == 'DSL':
        charge = np.random.uniform(40, 60)
    elif service == 'Fiber optic':
        charge = np.random.uniform(70, 110)
    else:  # Cable
        charge = np.random.uniform(55, 85)
    monthly_charges.append(round(charge, 2))

monthly_charges = np.array(monthly_charges)

# Calculate total charges (tenure * monthly_charges with some variation)
total_charges = []
for i in range(n_customers):
    # Add some variation for price changes over time
    variation = np.random.uniform(0.95, 1.05)
    total = tenure[i] * monthly_charges[i] * variation
    total_charges.append(round(total, 2))

total_charges = np.array(total_charges)

# Add-on services (correlated with contract type)
online_security = []
tech_support = []
for contract in contract_types:
    if contract == 'Month-to-month':
        online_security.append(np.random.choice(['Yes', 'No'], p=[0.2, 0.8]))
        tech_support.append(np.random.choice(['Yes', 'No'], p=[0.25, 0.75]))
    else:
        online_security.append(np.random.choice(['Yes', 'No'], p=[0.6, 0.4]))
        tech_support.append(np.random.choice(['Yes', 'No'], p=[0.65, 0.35]))

# Payment methods
payment_methods = np.random.choice(
    ['Electronic check', 'Mailed check', 'Bank transfer', 'Credit card'],
    size=n_customers,
    p=[0.35, 0.20, 0.25, 0.20]
)

# Paperless billing
paperless_billing = np.random.choice(['Yes', 'No'], size=n_customers, p=[0.6, 0.4])

# Support tickets (more for churners)
num_support_tickets = np.random.poisson(lam=2, size=n_customers)

# Average internet speed
avg_speed_mbps = []
for service in internet_services:
    if service == 'DSL':
        speed = np.random.uniform(10, 25)
    elif service == 'Fiber optic':
        speed = np.random.uniform(100, 500)
    else:  # Cable
        speed = np.random.uniform(50, 150)
    avg_speed_mbps.append(round(speed, 2))

avg_speed_mbps = np.array(avg_speed_mbps)

# Generate churn based on realistic patterns
churn = []
for i in range(n_customers):
    churn_probability = 0.15  # Base churn rate

    # Tenure effect (newer customers more likely to churn)
    if tenure[i] < 6:
        churn_probability += 0.25
    elif tenure[i] < 12:
        churn_probability += 0.15
    elif tenure[i] > 36:
        churn_probability -= 0.10

    # Contract type effect
    if contract_types[i] == 'Month-to-month':
        churn_probability += 0.20
    elif contract_types[i] == 'Two year':
        churn_probability -= 0.15

    # Payment method effect
    if payment_methods[i] == 'Electronic check':
        churn_probability += 0.10

    # Support tickets effect
    if num_support_tickets[i] > 4:
        churn_probability += 0.15
    elif num_support_tickets[i] > 2:
        churn_probability += 0.08

    # Price effect
    if monthly_charges[i] > 85:
        churn_probability += 0.08

    # No add-on services
    if online_security[i] == 'No' and tech_support[i] == 'No':
        churn_probability += 0.10

    # Cap probability between 0 and 1
    churn_probability = max(0, min(1, churn_probability))

    # Generate churn
    churn.append(1 if np.random.random() < churn_probability else 0)

# Create DataFrame
df = pd.DataFrame({
    'customer_id': customer_ids,
    'tenure': tenure,
    'monthly_charges': monthly_charges,
    'total_charges': total_charges,
    'contract_type': contract_types,
    'internet_service': internet_services,
    'online_security': online_security,
    'tech_support': tech_support,
    'payment_method': payment_methods,
    'paperless_billing': paperless_billing,
    'num_support_tickets': num_support_tickets,
    'avg_speed_mbps': avg_speed_mbps,
    'churn': churn
})

# Save to CSV
df.to_csv('teleconnect_customer_data.csv', index=False)

print("✅ Dataset created successfully!")
print(f"📊 Total customers: {len(df)}")
print(f"📉 Churn rate: {df['churn'].mean()*100:.2f}%")
print(f"💾 File saved as: teleconnect_customer_data.csv")
print("\nFirst few rows:")
print(df.head(10))

💡 6. Key Insights from EDA

📊 Major Findings

  1. Tenure Impact: Customers with shorter tenure (< 12 months) have significantly higher churn rates
  2. Contract Type: Month-to-month contracts show the highest churn rates (~40%), while two-year contracts have the lowest (~10%)
  3. Support Tickets: Customers with many support tickets (> 4) are much more likely to churn
  4. Payment Method: Electronic check users have higher churn rates compared to automatic payment methods
  5. Add-on Services: Customers without online security and tech support are more likely to churn
  6. Price Sensitivity: Higher monthly charges correlate with increased churn probability

🎯 Business Implications

  • Focus retention efforts on new customers (< 12 months tenure)
  • Incentivize longer-term contracts with discounts
  • Improve technical support quality to reduce support tickets
  • Promote automatic payment methods
  • Bundle add-on services to increase customer stickiness
  • Review pricing strategy for high-value packages
