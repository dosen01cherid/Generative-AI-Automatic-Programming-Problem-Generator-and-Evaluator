Part 3: Correlation Analysis

Exercise 3.1: Calculate Correlation Matrix

Calculate correlation between numerical variables:

# Select only numerical columns
numerical_cols = iris.select_dtypes(include=[np.number]).columns
print("Numerical columns:", numerical_cols.tolist())

# Calculate correlation matrix
correlation_matrix = iris[numerical_cols].corr()
print("\nCorrelation Matrix:")
print(correlation_matrix)

# Find highly correlated pairs (|correlation| > 0.8)
high_corr = correlation_matrix.abs() > 0.8
print("\nHighly Correlated Pairs:")
for i in range(len(correlation_matrix.columns)):
    for j in range(i+1, len(correlation_matrix.columns)):
        if high_corr.iloc[i, j]:
            print(f"{correlation_matrix.columns[i]} - {correlation_matrix.columns[j]}: {correlation_matrix.iloc[i, j]:.3f}")

Exercise 3.2: Visualize Correlation with Heatmap

Create an annotated heatmap:

# Create correlation heatmap
plt.figure(figsize=(10, 8))
sns.heatmap(correlation_matrix,
            annot=True,  # Show correlation values
            cmap='coolwarm',  # Color scheme
            center=0,  # Center colormap at 0
            square=True,  # Square cells
            linewidths=1,  # Add gridlines
            cbar_kws={"shrink": 0.8},  # Colorbar size
            fmt='.2f')  # Format numbers to 2 decimal places

plt.title('Correlation Heatmap - Iris Dataset', fontsize=16, fontweight='bold')
plt.tight_layout()
plt.savefig('correlation_heatmap.png', dpi=300, bbox_inches='tight')
plt.show()

print("✓ Heatmap saved as 'correlation_heatmap.png'")
💡 Interpretation Tips:
  • Red colors indicate positive correlation
  • Blue colors indicate negative correlation
  • Diagonal is always 1.0 (perfect correlation with itself)
  • Values close to 1 or -1 indicate strong correlation

Part 5: Advanced Scatter Plots

Exercise 5.1: Scatter Plot with Multiple Dimensions

Use color, size, and style to encode multiple variables:

# Using tips dataset
plt.figure(figsize=(12, 7))
scatter = plt.scatter(tips['total_bill'],
                     tips['tip'],
                     c=tips['size'],  # Color by party size
                     s=tips['total_bill']*10,  # Size by total bill
                     alpha=0.6,
                     cmap='viridis',
                     edgecolors='black',
                     linewidth=0.5)

plt.colorbar(scatter, label='Party Size')
plt.xlabel('Total Bill ($)', fontsize=12)
plt.ylabel('Tip ($)', fontsize=12)
plt.title('Tips Analysis: Bill vs Tip (sized by bill amount, colored by party size)',
          fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

Part 6: Boxplots and Violin Plots

Exercise 6.1: Boxplot for Outlier Detection

Visualize distribution and identify outliers:

# Create boxplots for Iris dataset
fig, axes = plt.subplots(2, 2, figsize=(14, 10))
features = ['sepal_length', 'sepal_width', 'petal_length', 'petal_width']

for idx, feature in enumerate(features):
    ax = axes[idx // 2, idx % 2]
    sns.boxplot(data=iris, x='species', y=feature, palette='Set3', ax=ax)
    ax.set_title(f'Distribution of {feature.replace("_", " ").title()}',
                 fontsize=12, fontweight='bold')
    ax.set_xlabel('Species', fontsize=10)
    ax.set_ylabel(feature.replace('_', ' ').title(), fontsize=10)
    ax.grid(True, alpha=0.3, axis='y')

plt.suptitle('Boxplots - Iris Features by Species', fontsize=16, fontweight='bold')
plt.tight_layout()
plt.show()

Exercise 6.2: Violin Plots for Distribution Visualization

Show full distribution with violin plots:

# Violin plots
fig, axes = plt.subplots(1, 2, figsize=(15, 6))

# Violin plot 1
sns.violinplot(data=iris, x='species', y='petal_length',
               palette='muted', inner='quartile', ax=axes[0])
axes[0].set_title('Petal Length Distribution by Species', fontsize=14, fontweight='bold')
axes[0].grid(True, alpha=0.3, axis='y')

# Violin plot 2 - Split by category
sns.violinplot(data=tips, x='day', y='total_bill', hue='sex',

Part 7: Interactive Visualizations with Plotly

Exercise 7.1: Interactive Scatter Plot

Create interactive scatter plot with hover information:

# Interactive scatter plot
fig = px.scatter(iris,
                 x='sepal_length',
                 y='sepal_width',
                 color='species',
                 size='petal_length',
                 hover_data=['petal_width'],
                 title='Interactive Iris Dataset Visualization',
                 labels={'sepal_length': 'Sepal Length (cm)',
                        'sepal_width': 'Sepal Width (cm)',
                        'species': 'Species'},
                 color_discrete_sequence=px.colors.qualitative.Set2)

fig.update_layout(
    hovermode='closest',
    template='plotly_white',
    height=600
)

fig.show()
# To save: fig.write_html('interactive_scatter.html')

Exercise 7.2: Interactive 3D Scatter Plot

Visualize data in 3D space:

# 3D scatter plot
fig_3d = px.scatter_3d(iris,
                       x='sepal_length',
                       y='sepal_width',
                       z='petal_length',
                       color='species',
                       size='petal_width',
                       hover_name='species',
                       title='3D Visualization of Iris Dataset',
                       labels={'sepal_length': 'Sepal Length',
                              'sepal_width': 'Sepal Width',
                              'petal_length': 'Petal Length'},
                       color_discrete_sequence=px.colors.qualitative.Vivid)

fig_3d.update_layout(
    scene=dict(
        xaxis_title='Sepal Length (cm)',
        yaxis_title='Sepal Width (cm)',
        zaxis_title='Petal Length (cm)'
    ),
    height=700
)

fig_3d.show()

Exercise 7.3: Interactive Correlation Heatmap

Create interactive heatmap with Plotly:

# Interactive heatmap
corr_matrix = iris[numerical_cols].corr()

fig_heatmap = go.Figure(data=go.Heatmap(
    z=corr_matrix.values,
    x=corr_matrix.columns,
    y=corr_matrix.columns,
    colorscale='RdBu',
    zmid=0,
    text=corr_matrix.values.round(2),
    texttemplate='%{text}',
    textfont={"size": 12},
    colorbar=dict(title="Correlation")
))

fig_heatmap.update_layout(
    title='Interactive Correlation Heatmap - Iris Dataset',
    xaxis_title='Features',
    yaxis_title='Features',
    height=600,
    template='plotly_white'
)

fig_heatmap.show()
